# Get kingdom names

Get kingdom names

## Usage

``` r
itis_kingdomnames(tsn = NULL, ...)
```

## Arguments

- tsn:

  One or more TSN's (taxonomic serial number)

- ...:

  Further arguments passed on to getkingdomnamefromtsn

## Examples

``` r
if (FALSE) { # \dontrun{
itis_kingdomnames(202385)
itis_kingdomnames(tsn=c(202385,183833,180543))
} # }
```
